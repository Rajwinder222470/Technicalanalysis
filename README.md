# BDA400 Assignment 5 - Technical Analysis using R, Development Phase

This repository contains separate base-R implementations for:
SMA, EMA, MACD, population standard deviation, linear regression, RSI,
Stochastic RSI, crossover, and crossunder.

## Run
1. Put all `.R` files in the same folder.
2. Set the RStudio working directory to this folder.
3. Run `source("test_all.R")`.
4. Review the Console output for each indicator.

No technical-analysis libraries are required.
